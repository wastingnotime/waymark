# Domain Background Knowledge

Waymark is a quiet private workspace for one person to record notes and
timestamped log entries, then inspect summaries derived from those durable
facts. A recurring subscription grants access to the workspace.

The first commercial model has one user, one payer, one workspace, one plan,
and one subscription-backed entitlement. There are no organizations, seats,
trials, coupons, credits, public profiles, or shared workspaces.

The product reference identifies these validation pressures:

- successful payment grants access;
- failed payment restricts or suspends access;
- recovered payment restores access;
- cancellation follows a billing-period rule;
- expiry removes access;
- an operator can inspect and intervene;
- recorded notes and logs remain durable while summaries are derived.

This document is source context for simulation expectation-gap detection. The
current hypothesis and slice contract remain in the neighboring artifacts.
